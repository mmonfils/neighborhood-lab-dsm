# Neighborhood Index

This directory holds the blueprints for logging open, shared community resources. While individual block grids track the shared resources of individual households, the Neighborhood Index is for tracking community assets that belong to the entire neighborhood space.

## Active Shared Indexes

* `neighborhood-index-template.csv`: Our direct template for tracking open, public community resources near our neighborhood areas.

## Basic Layout Rules

* **Track Resources, Not People:** This index is strictly for logging shared physical items and locations such as a community garden, a neighborhood message board, or a shared tool lending library. Never log individual household contact lists or private personal data here.
* **Keep Fields Clean:** Following our spreadsheet guidelines, keep entries simple. If an entry does not have information for a specific column, leave the field completely blank - placeholders are not recommended in order to prevent confusion.
* **Secure Local Data:** These files are designed to be run locally by independent organizers. We avoid third-party tracking programs to keep our data safe. We discuss best practices on our Substack newsletter so any block can use them to stay self-reliant.
