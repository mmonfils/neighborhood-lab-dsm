# Neighborhood Index

This directory holds the blueprints for logging open, shared community resources. While individual block grids track tools within private backyards, the Neighborhood Index is for tracking community assets that belong to the entire neighborhood space.

## Active Shared Indexes

*   `public-assets-template.csv`: Our direct template for tracking open, public community assets across our city streets.

## Basic Layout Rules

*   **Track Assets, Not People:** This index is strictly for cataloging shared physical items and locations (such as a community tool library, a neighborhood message board, or a shared lot water spigot). Never log individual household contact lists or private personal data here.
*   **Keep Fields Clean:** In line with our spreadsheet guidelines, keep entries simple and unadorned. If an entry does not have information for a specific column, leave the field completely blank—do not use placeholders or trailing programmatic markers.
*   **Sovereign Local Data:** These files are designed to be run locally by independent organizers. We reject third-party tracking programs to keep our data safe. We publish these standards on our [Substack newsletter](https://neighborhoodlabdsm.substack.com/) so any block can use them to build community self-reliance.
