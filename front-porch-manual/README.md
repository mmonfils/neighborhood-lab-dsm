# The Front Porch Manual
True stories, tips, and free templates showing how local block grids look after each other. Neighbors can use these simple, offline spreadsheets to coordinate local support, making it easy to share tools, skills, and everyday knowledge.

## Practical Tools & Blueprints
* `organizing-playbook.md`: Step-by-step organizing guide and privacy rules.
* `spreadsheet-blueprint.md`: How to set up your sheets and name your columns for your block.
* `sharing-tasks-fairly.md`: Simple ways to smoothly take turns with neighborhood tasks.
* `neighborhood-toolkit-template.csv`: A ready-to-use starter sheet with example rows to list your block's tools, skills, and knowledge.
* `exchange-log-template.csv`: A basic tracker for mutual aid, borrowed items, and shared time.
