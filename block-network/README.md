# The Front Porch Manual

This folder contains the practical guides for setting up an independent network on your own block.

## What is in this Folder

* street-guide.md: The basic playbook for organizing a block safely.
* neighborhood-toolkit.md: The blueprint explaining how to log local items and skills.
* block-roster.md: How to rotate tasks fairly so no one becomes a boss.
* neighborhood-toolkit-template.csv: The blank sheet for tracking block resources.
* exchange-log-template.csv: The blank sheet for keeping track of shared tasks.
