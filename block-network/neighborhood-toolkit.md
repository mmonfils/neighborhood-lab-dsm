# The Spreadsheet Blueprint

This guide explains how to use the local tool and skill tracker without tracking private data or putting price tags on help.

## Column Rules

* Household ID: Use simple codes like H01 or H02. Do not write down specific names or street numbers.
* Resource Type: Put things into basic categories like tools, skills, space, or care networks.
* Specific Description: Write down what the resource is, like a ladder, chainsaw, or backup childcare.
* How to Contact: Use direct, local methods like saying "knock on side door" or "send a text."
* Last Checked: Note when the information was updated, typically during spring yard cleanups or before winter storms.

## Safety Rules

* Never write down how much an item or favor is worth in money.
* Never track who owes what to whom. All trading is voluntary.
* Keep this spreadsheet stored locally on your own computer. Do not post it online.
