# Tracking the Blueprint

This directory provides a clear framework to document and simplify big picture trends so neighbors can look past the surface and protect their blocks early.

## Active Blueprint Layouts

* `big-picture-framework.md`: Our template framework for looking at regional developments, structural changes, and community transitions.

## Basic Layout Rules

* **Focus on Pressures, Not Neighbors:** This template is built to look closely at big picture patterns, institutional shifts, and outside messaging impacting our neighborhood space. Never use this file to log private data, contact lists, or personal details of individual block residents.
* **Keep Things Simple:** To match our repository guidelines, break down outside influences using everyday language so any neighbor can understand the broader local landscape at a glance.
