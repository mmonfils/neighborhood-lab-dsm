# Tracking the Blueprint

This directory provides a straightforward framework to document and simplify big picture pressures so neighbors can look past messaging and protect their blocks early.

## Active Blueprint Layouts

*   `big-picture-framework.md`: Our template framework for looking at regional pressures, institutional developments, and community transitions.

## Basic Layout Rules

*   **Focus on Pressures, Not Neighbors:** This template is built to look closely at big picture developments, institutional shifts, and outside messaging impacting our neighborhood space. Never use this file to log private data, contact lists, or personal details of individual block residents.
*   **Keep Things Simple:** In alignment with our repository guidelines, break down outside pressures using plain-spoken, everyday language so any neighbor can understand the broader local landscape at a glance.
