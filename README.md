# Neighborhood Lab DSM

A shared notebook with simple tools to track local facts, map our blocks, and look out for each other. This digital workshop serves as the open-source repository for our templates, guides, and flat-file asset maps.

## Repository Map
*   `front-porch-manual/`: Practical, street-level organizing tools and templates.
*   `neighborhood-index/`: Flat-file templates for indexing public resources and community wealth.
*   `tracking-the-blueprint/`: A local research space to document macro changes affecting central Iowa blocks.

## Front Porch Communication
Our stories, insights, and structural updates are shared directly with neighbors over the backyard fence via our Substack newsletter publication.
